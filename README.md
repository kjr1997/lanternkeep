Lanternkeep — a moth-warden defends the last lantern against the shades. Fly with WASD or arrows, aim with the mouse, hold click or Space to shoot. Shades drift in from the dark to drink the lantern's light; between waves, choose one blessing. Survive 10 waves and dawn breaks. Built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: the game is plain static files under `game/`.
